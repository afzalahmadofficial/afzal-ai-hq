# Content Repurposing Workflow

**Version:** 1.0

**Project:** Afzal Ahmad AI HQ

**Workflow:** One Core Idea → Multiple Platform Formats

**Status:** Approved

**Priority:** High

---

# 1. Objective

Turn one validated original idea into multiple useful, platform-specific content assets without simply duplicating the same content everywhere.

The goal is to increase content efficiency while preserving originality, quality, context, and platform fit.

---

# 2. Core Principle

**Create once at the insight level, adapt many times at the format level.**

The system should reuse the underlying insight, evidence, examples, and strategic angle while rewriting the presentation for each platform.

---

# 3. High-Level Flow

```text
Validated Research / Core Insight
              ↓
        Master Content Brief
              ↓
       Original Core Asset
              ↓
      ┌───────┼────────┐
      ↓       ↓        ↓
   YouTube  LinkedIn   Blog
      ↓       ↓        ↓
      └───────┼────────┘
              ↓
        Newsletter / Short-form
              ↓
           Analytics
              ↓
       Learning + Memory
```

---

# 4. Master Content Brief

Before repurposing, create one canonical brief containing:

- Core idea
- Audience
- Problem
- Main argument
- Evidence
- Source references
- Original insight
- Examples
- Key takeaways
- Brand perspective

The master brief is the source of truth for derivative content.

---

# 5. Originality Rules

Repurposing must not become repetitive publishing.

Each platform version should:

- Use platform-appropriate structure.
- Add useful context where needed.
- Avoid mechanically copying the same wording.
- Preserve factual accuracy.
- Maintain the original source attribution where relevant.

Competitor content must never be used as text to rewrite or disguise as original work.

---

# 6. YouTube Version

A strong insight may become:

- Video topic
- Hook
- Title options
- Video outline
- Full script
- Description
- Chapters where appropriate
- Thumbnail concept
- Short-form clip ideas

The video should provide enough context to stand on its own.

---

# 7. LinkedIn Version

Convert the core insight into one focused professional post.

Possible structures:

- Insight → explanation → lesson
- Problem → mistake → better approach
- Observation → evidence → implication
- Framework → examples → takeaway

Avoid copying the YouTube script or article paragraph-by-paragraph.

---

# 8. Blog Version

Expand the insight into a structured article when search intent and audience value justify it.

Possible structure:

- Clear introduction
- Direct answer
- Context
- Main sections
- Evidence/examples
- Practical implications
- Conclusion
- Useful FAQs when genuinely relevant

Apply SEO and GEO optimization separately through their designated agents.

---

# 9. Newsletter Version

Create a concise editorial version containing:

- What happened or what was learned
- Why it matters
- Afzal Ahmad's interpretation
- Recommended action
- Optional links to the longer content

The newsletter should add value rather than simply announce another platform post.

---

# 10. Short-Form Version

Long-form content may produce short-form concepts such as:

- One key lesson
- One surprising fact
- One practical tip
- One misconception
- One question

Short-form content must remain accurate and should not remove context in a misleading way.

---

# 11. Platform Adaptation Matrix

| Source Asset | YouTube | LinkedIn | Blog | Newsletter | Short-form |
|---|---|---|---|---|---|
| Research insight | Video | Post | Article | Brief | Clip/idea |
| Tutorial | Tutorial video | Framework post | Guide | Quick lesson | Tip |
| Industry news | Analysis video | Commentary | Analysis article | News brief | Key update |
| Case study | Breakdown | Lesson post | Detailed case study | Summary | Key result |

---

# 12. Quality Gate

Before each derivative asset is approved, check:

- Is it useful on its own?
- Is it appropriate for the platform?
- Is the wording original?
- Are facts still accurate?
- Are sources preserved where required?
- Has context been removed in a misleading way?
- Does it add a distinct value or perspective?

---

# 13. Publishing Order

A recommended sequence is:

1. Validate research.
2. Create master brief.
3. Produce strongest core asset.
4. Adapt into secondary formats.
5. Review all assets.
6. Publish according to the content calendar.
7. Measure performance.
8. Store learnings.

The exact order may change depending on the campaign and platform.

---

# 14. Analytics Feedback

Measure each platform separately.

Do not assume that success on one platform guarantees success on another.

Useful learning signals include:

- Views
- Impressions
- Engagement
- Watch time
- Clicks
- Audience retention
- Comments/questions
- Follower or subscriber changes

These insights should feed the next content brief.

---

# 15. Memory Integration

Store relationships between assets so the system knows that multiple pieces originated from the same core idea.

Example:

```text
Core Idea #102
   ├── YouTube Video #45
   ├── LinkedIn Post #88
   ├── Blog Article #31
   └── Newsletter #17
```

This prevents accidental duplication and helps measure campaign-level performance.

---

# 16. AI Model Strategy

Use the AI Model Tool for transformations and drafting, while keeping the master brief and source evidence available to maintain consistency.

Routine transformations may use suitable free/low-cost models.

Important factual or strategic outputs should receive appropriate review.

---

# 17. Failure Handling

If a derivative asset fails quality review:

- Keep the master brief unchanged.
- Revise only the affected asset.
- Recheck factual consistency.
- Do not publish the failed version.

---

# 18. Success Criteria

The workflow succeeds when one validated insight can efficiently produce several genuinely useful, original, platform-appropriate assets while maintaining consistent facts and a clear brand perspective.
