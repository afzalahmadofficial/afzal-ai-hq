# Executive Summary

This document defines the standard frameworks for creating content across all supported platforms.

Every AI agent responsible for content creation must follow these frameworks to ensure consistency, quality, and audience value.

The objective is not to create viral content at any cost, but to build long-term authority and trust.

---

# Universal Content Formula

Every content asset should follow this sequence:

Attention

↓

Context

↓

Problem

↓

Insight

↓

Solution

↓

Example

↓

Action Steps

↓

Call to Action

---

# Universal Hook Formula

Hooks should achieve at least one of the following:

- Create curiosity
- Challenge a common belief
- Present surprising data
- Highlight a costly mistake
- Introduce a practical framework

Examples:

- Most people use AI the wrong way.
- This one workflow saved me 10 hours every week.
- The biggest mistake professionals make with ChatGPT.
- Stop using AI like a chatbot.

---

# LinkedIn Framework

Structure:

1. Hook
2. Context
3. Problem
4. Story or Example
5. Lesson
6. Action Steps
7. CTA

Length:

150–350 words

---

# YouTube Framework

Structure:

1. Hook
2. Introduce the problem
3. Explain why it matters
4. Demonstrate the solution
5. Examples
6. Key takeaways
7. CTA

Recommended Duration:

8–15 minutes

---

# Blog Framework

Structure:

- SEO Title
- Meta Description
- Introduction
- Problem
- Solution
- Examples
- Frequently Asked Questions
- Conclusion

Target Length:

1500–3000 words

---

# Newsletter Framework

Structure:

- Personal introduction
- One major insight
- One practical framework
- One recommendation
- Closing thoughts

Target Length:

600–1200 words

# CTA Library

Preferred CTAs:

- Save this for later.
- Share this with your team.
- Try this workflow today.
- Which strategy would you use?
- What would you add?
- Follow for practical AI insights.

Avoid manipulative or misleading CTAs.

---

# AI Content Rules

Every AI-generated content piece must:

- Provide practical value.
- Be factually accurate whenever possible.
- Avoid unsupported claims.
- Match the brand voice.
- Respect platform best practices.
- Include a clear takeaway.

---

# Quality Checklist

Before publication:

✓ Strong Hook

✓ Valuable Insight

✓ Logical Structure

✓ Practical Examples

✓ Clear CTA

✓ Correct Grammar

✓ Consistent Brand Voice

✓ Audience Focus
